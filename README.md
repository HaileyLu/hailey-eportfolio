# Hailey Lu — Biomedical Engineering ePortfolio

A static, accessible tabbed portfolio prepared for GitHub Pages. Content is based on Hailey's supplied landing page, resume, internship reflection and cover letter.

## Publish with GitHub Pages

1. Create a GitHub repository and upload the contents of this folder to its root.
2. In the repository, open **Settings → Pages** and select **Deploy from a branch**, `main`, and `/ (root)`.
3. The site will be at `https://USERNAME.github.io/REPOSITORY/` (replace the placeholders with your actual names). Add that URL to the top of the Word submission.

The original resume PDF is in `assets/` for download. The reflection text is included on the page; workplace photographs from the supplied PDF are omitted from this public-ready package. The site is static; no install or build command is needed. Open `index.html` locally to review the content before publishing.
